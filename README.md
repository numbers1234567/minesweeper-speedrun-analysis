# minesweeper-speedrun-analysis

Thousands of Minesweeper solvers are already out there.
I'm interested in looking at this from a different angle: how can we model human play? What can such a model teach us about how to optimize our own runs?

It's not an obvious problem. Humans have all sorts of limitations. We have slow reaction times. We can only focus on a single part of the board. We can't move the mouse in a perfectly straight line. We have a limited, imprecise short-term memory.
